### Removed

- Unused metric dimensions (roadmap B.4): network receive and transmit, disk read and write, ephemeral storage, and PVC request and usage are no longer collected, stored, rolled up, returned by the metrics API or exported on `/metrics` (`greenkube_pod_network_receive_bytes`, `greenkube_pod_network_transmit_bytes`, `greenkube_pod_disk_read_bytes`, `greenkube_pod_disk_write_bytes`). The range collection sends 11 Prometheus range queries per chunk instead of 16, and no longer runs the 3 instant PVC queries per window. The measured-ledger input no longer records `traffic_ratio`. The columns `network_receive_bytes`, `network_transmit_bytes`, `disk_read_bytes`, `disk_write_bytes`, `storage_request_bytes`, `storage_usage_bytes`, `ephemeral_storage_request_bytes` and `ephemeral_storage_usage_bytes` keep their old values; migration 0320 marks them deprecated and a later migration drops them (see `docs/upgrading.md`, "Removed metric dimensions").
