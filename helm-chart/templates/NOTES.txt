{{- if and (or (.Values.ingress | default dict).enabled (.Values.httpRoute | default dict).enabled) (not .Values.config.trustedProxyIps) }}

* SECURITY WARNING: GreenKube is exposed through an Ingress or HTTPRoute but
  config.trustedProxyIps is empty. Every request then appears to come from the
  ingress controller: sign-in lockouts and API rate limits are shared by all users,
  and one client can exhaust them for everyone. Set config.trustedProxyIps to the
  ingress controller (or gateway) pod addresses, for example the pod CIDR.
{{- end }}
