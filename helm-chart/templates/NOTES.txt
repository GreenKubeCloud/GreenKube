2. Sign in with the API key{{ if .Values.config.api.enabled }} (the UI asks for it on the first protected request){{ end }}:
     kubectl -n {{ .Release.Namespace }} get secret {{ $apiKeySecret }} -o jsonpath='{.data.GREENKUBE_API_KEY}' | base64 -d; echo
{{- if .Values.secrets.existingSecret }}
   The key comes from your Secret {{ .Values.secrets.existingSecret }} (secrets.existingSecret).
{{- else if .Values.secrets.apiKey }}
   The key is the value of secrets.apiKey.
{{- else }}
   The key was generated once by the {{ include "greenkube.credentialsBootstrapName" . }} hook.
   Secret {{ include "greenkube.secretName" . }} is not part of the Helm release, so upgrades and
   Argo CD/Flux syncs never rotate it and `helm uninstall` keeps it, like the
   PostgreSQL volume. For a fully declarative (GitOps) setup, create your own
   Secret and set secrets.existingSecret instead.
{{- end }}

{{- if eq .Values.profile "production" }}

* Production profile:
  API, controller, and automation worker run as separate Deployments.
  Database migrations run as a post-install/post-upgrade Job before the API
  readiness check; bundled PostgreSQL is awaited before migration starts. The
  controller uses the {{ include "greenkube.leaseName" . }} Lease for active/standby coordination.
{{- else }}

* Standalone profile:
  Collector and API run together in one replica for simple installations.
{{- end }}

* Logs:
  kubectl logs -l app.kubernetes.io/name={{ include "greenkube.name" . }} -n {{ .Release.Namespace }} -f

* Prometheus:
  GreenKube auto-discovers Prometheus in your cluster — no configuration needed.
  If Prometheus isn't installed yet, you can use https://github.com/prometheus-operator/kube-prometheus.
{{- if not .Values.config.prometheus.url }}
  If auto-discovery fails, set the URL manually:
    --set config.prometheus.url=http://prometheus-server.monitoring.svc.cluster.local:80
{{- end }}

* No Electricity Maps token? GreenKube uses default intensity ({{ .Values.config.defaultIntensity }} gCO₂e/kWh).
   For accurate data, set: secrets.electricityMapsToken
   Or switch the provider to Wattnet (EU-only, free): config.electricityProvider=wattnet + secrets.wattnetEmail/wattnetPassword
