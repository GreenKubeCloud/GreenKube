{{- if .Values.config.api.enabled }}

* Dashboard & API:
  kubectl port-forward svc/{{ include "greenkube.fullname" . }}-api {{ .Values.config.api.port }}:{{ .Values.config.api.port }} -n {{ .Release.Namespace }}
  → http://localhost:{{ .Values.config.api.port }}
{{- end }}

{{- if eq .Values.profile "production" }}
* Production profile:
  API, controller, and automation worker run as separate Deployments.
  Database migrations run as a pre-install/pre-upgrade Job and the controller
  uses the {{ include "greenkube.leaseName" . }} Lease for active/standby coordination.
{{- else }}
* Standalone profile:
  Collector and API run together in one replica for simple installations.
{{- end }}

* Logs:
  kubectl logs -l app.kubernetes.io/name={{ include "greenkube.name" . }} -n {{ .Release.Namespace }} -f

* Prometheus:
  GreenKube auto-discovers Prometheus in your cluster — no configuration needed.
  If Prometheus isn't installed yet, you can use https://github.com/prometheus-operator/kube-prometheus.
{{- if not .Values.config.prometheus.url }}
  If auto-discovery fails, set the URL manually:
    --set config.prometheus.url=http://prometheus-server.monitoring.svc.cluster.local:80
{{- end }}

* No Electricity Maps token? GreenKube uses default intensity ({{ .Values.config.defaultIntensity }} gCO₂e/kWh).
   For accurate data, set: secrets.electricityMapsToken
   Or switch the provider to Wattnet (EU-only, free): config.electricityProvider=wattnet + secrets.wattnetEmail/wattnetPassword
